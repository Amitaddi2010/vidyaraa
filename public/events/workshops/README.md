## General Guidelines

### Image Specifications
- **Main Images**: 1200x800px recommended
- **Gallery Images**: 800x800px recommended (square)
- **Format**: JPG or PNG
- **Quality**: Web-optimized, under 500KB per image

### File Naming Convention
- Use kebab-case: `{workshop-name}-{number}.jpg`
- Numbers 1-6 for complete gallery
- Main image should always be `-1.jpg`

### Upload Process
1. Add images to this folder
2. Follow naming conventions exactly
3. Test on website after upload
4. Update EventsPage.jsx if adding new workshops

## Notes
- Workshops focus on hands-on learning
